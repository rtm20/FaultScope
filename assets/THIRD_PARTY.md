# Demo browser dependencies

These unmodified public packages are stored locally so the HTML demo can open
directly without a build step or development server.

| Package | Pinned release | Download source | License |
| --- | --- | --- | --- |
| Three.js | 0.160.0 | https://unpkg.com/three@0.160.0/build/three.min.js | MIT; see three-LICENSE.txt |
| Lucide | 0.468.0 | https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js | See lucide-LICENSE.txt, including the upstream icon notices |

Three.js uses its classic browser build here to retain direct file-opening
support. The illustrated equipment is independently created from geometry in
the demo, not copied from a manufacturer's model or represented as a digital
twin. The datasets used in earlier research are not bundled into this page.

Manrope, Space Grotesk and IBM Plex Mono are requested from Google Fonts.
The page falls back to installed fonts if that request is unavailable.

The interface is a local concept with synthetic samples and scripted AI
activity. No credentials, external model endpoint, or equipment integration
are used.
